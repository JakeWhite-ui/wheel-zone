## 1. Атмосфера

**Это не сайт шиномонтажа. Это витрина склада дисков.**

Главный товар — диски, не шины (два из трёх отзывов про выбор дисков и ремонт дисков).
Конкурент Tire Zone в соседнем здании владеет темой шин — 1 733 отзыва. Лезть туда нечего.
Wheel Zone берёт то, чего у соседа нет: **стена дисков + ремонт диска**.

**Три слова: СКЛАД · МЕТАЛЛ · РАЗМЕР.**

**Камертон:** *Назови размер — остальное наша работа.*

Сайт ведёт себя как прилавок: первое, что он спрашивает — твой размер. Не «мы лидеры рынка».

## 2. Палитра — ОДИН акцент

```css
:root{
  /* подложки */
  --ink:        #0B0E12;   /* фон страницы */
  --ink-2:      #11151B;   /* секция-подложка */
  --ink-3:      #171C24;   /* карточка */
  --ink-4:      #1E242E;   /* карточка hover */
  --line:       #272F3A;   /* обводка 1px */
  --line-lit:   #3A4553;   /* обводка hover */

  /* светлая зона (каталог шин — единственная светлая секция) */
  --paper:      #F2F5F8;
  --paper-2:    #E4EAF0;
  --paper-ink:  #0B0E12;

  /* текст */
  --text:       #E8EDF3;   /* 17.9:1 на --ink */
  --muted:      #93A1B2;   /*  7.3:1 на --ink */
  --dim:        #5E6B7B;   /* только для декора, НЕ для текста */

  /* ЕДИНСТВЕННЫЙ акцент — синий логотипа #057CBC, две светлоты одного тона */
  --accent:     #057CBC;   /* заливки, кнопки. Белый текст на нём = 4.56:1 ✅ */
  --accent-lit: #3BA7E8;   /* текст и ссылки на тёмном = 7.25:1 ✅ */
  --accent-dim: rgba(5,124,188,.14);  /* подсветка карточки, обводки */

  --radius:     4px;       /* почти прямые углы — это склад, не финтех */
  --radius-lg:  8px;
}
```

**Запрещено:** любой второй акцентный тон. Ни зелёного «успех», ни красного «скидка»,
ни жёлтого. Срочность и акции — только через **вес шрифта и размер**, не через цвет.
Жёлтая стена в `showroom.webp` гасится до 35% яркости / частично обесцвечивается.

## 7. Анимации — уровень **L2**, и это осознанно

**L1 мало:** маркетплейс без отклика на наведение выглядит мёртвым, карточки должны реагировать.
**L3 вредит:** pin-scrub и Lenis ломают главный сценарий — человек со сколом на диске хочет
за 15 секунд найти размер и нажать WhatsApp. Скролл-джекинг на каталоге это саботаж.

**Что входит в L2:**
- Scroll-reveal — **rAF-троттлед обход по `getBoundingClientRect()`**, НЕ IntersectionObserver.
  Элемент, проскочивший между кадрами, не должен навсегда зависнуть на `opacity: 0`.
  Сдвиг 16px + opacity, 480ms, стагger 60ms, максимум 6 элементов в волне.
- Spotlight на карточках — `pointermove` через rAF, обновляются только CSS-переменные.
- Бегущая строка спеков — `transform: translate3d`, CSS-анимация, `will-change: transform`,
  пауза через sweep-проверку видимости.
- Счётчики 4.4 / 40 — один раз, 900ms, `requestAnimationFrame`.
- **Хитрость:** диск в hero поворачивается на угол, привязанный к `scrollY`
  (`rotate(scrollY * 0.12deg)`), в том же rAF-обходе. Колесо катится, пока ты скроллишь.
  Замечают не сразу. Отключается при `prefers-reduced-motion`.

**Чего не будет:** WebGL (0 на страницу), Lenis, ScrollTrigger pin, кастомного курсора,
`filter: blur()` на движущемся, параллакса фоновых картинок на мобиле.

## 8. Do's and Don'ts

**Do**
1. Первый экран спрашивает размер. Не рассказывает о компании.
2. Все размеры, PCD, ET, индексы — моноширинным. Это язык товара.
3. Цена отсутствует → честное `Price on request`, и тут же кнопка «уточнить в WhatsApp».
4. Фото дисков режутся в портрет 4:5 — диск круглый, в пейзаже он тонет.
5. Ремонт диска показывается как отдельный товар, а не строчка в списке услуг.
6. Отзывы — три настоящих, дословно, с именами. Больше у нас нет.
7. «4.4 на Google» — текстом и ссылкой на профиль. В JSON-LD только `LocalBusiness`.
8. Телефон, WhatsApp, адрес кликабельны везде, где показаны.

**Don'ts — анти-паттерны конкретно для этого бренда**
1. ❌ **Фальшивые отзывы со старого сайта.** John Doe и Jane Smith из Нью-Йорка удаляются совсем.
2. ❌ **`+1234567890` и `support@wheelzone.com`.** Заглушки конструктора, не контакты.
3. ❌ **Фото с вывеской «EXPRESS TYRE SHOP».** Реклама чужого шиномонтажа на сайте клиента.
4. ❌ **«500+ довольных клиентов», «10 лет на рынке».** Магазин новый, отзывам год. Цифры только 4.4 и 40.
5. ❌ **`aggregateRating` / `Review` в JSON-LD.** Рейтинг собран Google — это спам по их правилам.
6. ❌ **Oswald 96px на белом фоне.** Так сделаны Grand Power и Milad. Третий раз = один и тот же сайт.
7. ❌ **Одинаковая сетка карточек 3×N.** Это склад дисков разного калибра, bento обязателен.
8. ❌ **Второй акцентный цвет.** Ни «зелёный в наличии», ни «красный скидка».
9. ❌ **Эмодзи вместо иконок.** В логотипе их нет — значит их нет нигде.
10. ❌ **Кнопки «Learn more» / «Get started».** Только «WhatsApp us», «Call 04 576 2199», «Check my size».
11. ❌ **Секции-наполнители.** Нет контента → нет секции. Пустоту решает композиция.
12. ❌ **Нарисованные SVG-диски вместо фото.** Нет фото — честный плейсхолдер `[фото: стеллаж дисков]`.
13. ❌ **Полное расписание недели.** Знаем только «закрывается в 23:00» — больше ничего не пишем.

## 9. Респонсив

| Брейкпоинт | Что происходит |
|---|---|
| **375–479** | одна колонка; поля ввода размера в ряд, `--fs-mega` падает до 64px; меню → полноэкранная панель; sticky-полоса снизу: «WhatsApp» + «Call» 50/50, высота 56px; bento → стопка; бегущая строка остаётся, скорость −30% |
| **480–767** | то же, крупная плитка bento 4:5 на всю ширину |
| **768–1023** | 2 колонки; фильтры — горизонтальная скролл-лента чипов; меню ещё бургер |
| **1024–1365** | полное меню; bento 12 колонок; фильтры sticky слева |
| **1366–1920** | контейнер 1320px и больше не растёт; поля растут, не контент |
| **>1920** | фон тянется, контейнер стоит; `--fs-mega` зажат на 200px |

- Тач-таргеты **≥44×44px**, чипы фильтров на мобиле 44px.
- Горизонтального скролла нет нигде: `overflow-x: clip` на `body`, бегущая строка в своём `overflow: hidden`.
- Hero на мобиле `100svh`, не `100vh`.
- `prefers-reduced-motion: reduce` → все `transform`-анимации и вращение диска выключаются,
  reveal превращается в мгновенный `opacity: 1`.

## 10. Калькулятор — две машины в одной

### A. Декодер и подбор размера (считает, а не выдумывает)
Ввод `225/45 R18 94W` → раскладывает: ширина 225 мм, профиль 45%, диаметр 18″,
индекс нагрузки 94 = 670 кг, индекс скорости W = 270 км/ч.
Считает внешний диаметр по формуле и предлагает **альтернативные размеры в пределах ±3%
окружности качения** (плюс-сайзинг). Это чистая арифметика по общепринятым таблицам —
не выдуманные данные, можно показывать до прайса.

### B. Сборка заказа → WhatsApp
`размер → количество (1–4) → услуги (монтаж, балансировка, развал, азот, вентиль, утилизация, ремонт диска)`
→ собирает точный текст заявки и открывает WhatsApp с ним.

**Цены:** объект `PRICES` в коде **намеренно пустой**. Пока Александр не прислал прайс —
калькулятор пишет `Price on request` и всё равно собирает заявку с точным составом.
Как только приходят цифры — заполняется один объект, и калькулятор начинает считать суммы.
Выдуманных цен не будет.

**Хитрость №2:** счётчик количества на `4` переключает подпись на `FULL SET`.

## 13. Технический минимум

- Один `index.html`, инлайн CSS и JS, без сборки. Отдельный `catalog.json` + `?v=N` на нём.
- `?v=N` на всех внешних ресурсах.
- Все `<img>` с `width`/`height`, `loading="lazy"` кроме hero, WebP.
- `<title>`, `meta description`, OG-картинка, favicon из логотипа.
- JSON-LD: **только** `LocalBusiness` — имя, адрес, телефон, гео. Без рейтинга и отзывов.
- Контраст текста ≥ 4.5:1 — проверено на `--text`, `--muted`, `--accent-lit`.
- Деплой: GitHub Pages из `main`, аккаунт JakeWhite-ui.
